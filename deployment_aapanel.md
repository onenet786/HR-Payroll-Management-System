# 🚀 Production Deployment Guide: aaPanel (Node.js + PostgreSQL)

This guide provides step-by-step instructions to deploy the **Bin Ishaq HR & Payroll Management System** on **aaPanel** using Node.js Project Manager, PostgreSQL, Nginx, and SSL.

---

## 🏗️ Architecture Overview

- **Frontend**: React 19 + TypeScript + Vite (Compiled static bundle inside `dist/`).
- **Backend API**: Express Node.js application (`server.cjs`).
- **Database**: PostgreSQL 14+ System of Record (`hr_payroll`).
- **Web Server**: Nginx as Reverse Proxy with SSL (HTTPS) terminating traffic to `127.0.0.1:8080`.

---

## 📋 Prerequisites on aaPanel

1. **aaPanel Installed** on Ubuntu / Debian / AlmaLinux / CentOS.
2. **Nginx Installed** (via App Store).
3. **Node.js Version Manager** (via App Store) with Node `v18.x` or `v20.x` LTS installed.
4. **PostgreSQL Manager** (via App Store) or local PostgreSQL server running on port `5432`.

---

## 🗄️ Step 1: Create & Migrate PostgreSQL Database

1. Open **aaPanel** -> **Database** -> **PostgreSQL**.
2. Click **Add DB**:
   - **Database Name**: `hr_payroll`
   - **DB User**: `hr_user`
   - **Password**: Generate a strong password (e.g. `StrongPass786!`).
   - **Access Rights**: `Localhost (127.0.0.1)`
3. *(Optional)* If your OS does not have PostgreSQL contrib extensions installed, run:
   ```bash
   # On Ubuntu / Debian:
   sudo apt-get update && sudo apt-get install -y postgresql-contrib

   # On CentOS / AlmaLinux / Rocky Linux:
   sudo dnf install -y postgresql-contrib
   ```
4. Open aaPanel Terminal or SSH into your VPS and run the database migration scripts:
   ```bash
   sudo -u postgres psql -d hr_payroll -f /www/wwwroot/hr-payroll/postgres/migrations/001_initial.sql
   sudo -u postgres psql -d hr_payroll -f /www/wwwroot/hr-payroll/postgres/migrations/002_relational_tables.sql
   ```
   *Alternatively, run the automated migration runner: `node scripts/postgres-migrate.cjs`*

## 📂 Step 2: Upload Minimal Production Package & Configure Environment

To keep your deployment lightweight and clean, you only need to upload the **essential web production files**. You do **NOT** need Electron desktop, Kiosk native apps, or development scratch folders.

---

### 📦 Minimal Required Files & Folders

When deploying to `/www/wwwroot/hr-payroll/`, upload **ONLY** these files and folders:

| File / Folder | Type | Description |
| :--- | :--- | :--- |
| 📄 `server.cjs` | **File** | Main Express server entry point |
| 📄 `package.json` | **File** | Node.js production dependencies |
| 📄 `package-lock.json` | **File** | Exact locked package versions |
| 📄 `.env` | **File** | Production environment variables |
| 📁 `dist/` | **Folder** | Compiled frontend app bundle (from `npm run build`) |
| 📁 `server/` | **Folder** | Backend DB queries & Auth module logic |
| 📁 `postgres/` | **Folder** | Database migration SQL scripts (`001_initial.sql`) |

---

### 🚫 Folders to EXCLUDE (Do NOT Upload)

You can safely **exclude / delete** the following folders to save bandwidth and server space:

- ❌ `electron/` *(Desktop App wrapper)*
- ❌ `kiosk/` or `kiosk-native/` *(Hardware kiosk terminal)*
- ❌ `scratch/` *(Temporary test scripts)*
- ❌ `node_modules/` *(Will be installed on server via `npm install --production`)*
- ❌ `.git/` / `.github/` *(Version control)*

---

### ⚡ Server Installation Commands

Once the minimal files are uploaded to `/www/wwwroot/hr-payroll/`:

1. Open aaPanel Terminal or SSH into your VPS:
   ```bash
   cd /www/wwwroot/hr-payroll
   ```
2. Install production Node dependencies:
   ```bash
   npm install --production
   ```

Create `.env` inside `/www/wwwroot/hr-payroll/.env`:

## ⚡ Step 3: Configure aaPanel Node.js Project Manager

> 💡 **Important Directory Layout Note**:
> - `server.cjs` is located in the **ROOT project folder** (`/www/wwwroot/hr-payroll/server.cjs`).
> - `dist/` is the subfolder generated by `npm run build` containing compiled frontend static assets (`/www/wwwroot/hr-payroll/dist/`).
> - When `server.cjs` runs from the root folder, it automatically serves the API routes (`/api/...`) AND hosts the static files from `./dist/`.
> - Therefore, the **Project Path in aaPanel MUST be set to the root folder** `/www/wwwroot/hr-payroll` (NOT `/dist`).

```
📁 /www/wwwroot/hr-payroll/             <-- aaPanel Project Path
├── 📄 server.cjs                       <-- Start Command: node server.cjs
├── 📄 .env                             <-- Environment Variables
├── 📄 package.json
├── 📁 server/                          <-- Backend Auth & Database logic
├── 📁 postgres/                        <-- Migration SQL scripts
└── 📁 dist/                            <-- Auto-served by server.cjs
    ├── 📄 index.html
    └── 📁 assets/
```

1. Open **aaPanel** -> **App Store** -> **Node.js Project Manager**.
2. Click **Add Node Project**:
   - **Project Path**: `/www/wwwroot/hr-payroll` *(Select the root folder containing `server.cjs`)*
   - **Project Name**: `hr-payroll-system`
   - **Run Opt**: `Custom Command`
   - **User**: `www`
   - **Node Version**: Select `v20.x` or `v18.x`
   - **Start Command**: `node server.cjs`
   - **Port**: `8080`
3. Click **Submit**.
4. Check project status—it should show **Running** on port `8080`.

## 🔒 Step 4: Configure Domain, Nginx Reverse Proxy & SSL

1. Open **aaPanel** -> **Website** -> **Add Site**:
   - **Domain**: `hr.yourdomain.com`
   - **Target Dir**: `/www/wwwroot/hr-payroll`
   - **FTP / Database**: None
2. **Enable SSL (HTTPS)**:
   - Click on the domain name `hr.yourdomain.com` -> **SSL** -> **Let's Encrypt**.
   - Select domain and click **Apply**.
   - Enable **Force HTTPS**.
3. **Configure Nginx Reverse Proxy**:
   - Go to Domain Settings -> **Reverse Proxy** -> **Add Reverse Proxy**:
     - **Proxy Name**: `NodeBackend`
     - **Target URL**: `http://127.0.0.1:8080`
     - **Sent Domain**: `$host`
   - Click **Save**.
4. *(Optional)* Verify Nginx config includes WebSocket headers for real-time sync:
   ```nginx
   location / {
       proxy_pass http://127.0.0.1:8080;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection "upgrade";
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
       proxy_cache_bypass $http_upgrade;
   }
   ```

## 🏁 Step 5: System Onboarding & Verification

1. Open your browser and navigate to `https://hr.yourdomain.com`.
2. Because the PostgreSQL database is fresh (0 users), the **Database Setup Wizard** will launch automatically.
3. Fill in:
   - **Company Name**: e.g., `Bin Ishaq Logistics Ltd.`
   - **Super Admin Name**: `System Administrator`
   - **Super Admin Email**: `admin@yourdomain.com`
   - **Super Admin Password**: Set a strong password.
4. Click **Initialize Database & Sign In**.
5. Your HR & Payroll Management System is now live in production!

## 🛠️ User Account Troubleshooting (PostgreSQL)

If a user account like `kiosk@gmail.com` returns "Invalid email or password" on login, verify the user record in PostgreSQL on your aaPanel VPS:

### 1. View all active user accounts in PostgreSQL:
```bash
sudo -u postgres psql -d hr_payroll -c "SELECT id, username, email, status, role_id FROM users;"
```

### 2. Reset or Create `kiosk@gmail.com` with a plain password (e.g. `kiosk123456`):
```bash
sudo -u postgres psql -d hr_payroll -c "
INSERT INTO users (id, username, email, role_id, status, data)
VALUES (
  'usr-kiosk',
  'kiosk@gmail.com',
  'kiosk@gmail.com',
  'role-admin',
  'Active',
  '{\"id\":\"usr-kiosk\",\"username\":\"kiosk@gmail.com\",\"email\":\"kiosk@gmail.com\",\"fullName\":\"Kiosk Terminal\",\"password\":\"kiosk123456\",\"roleId\":\"role-admin\",\"status\":\"Active\"}'::jsonb
)
ON CONFLICT (id) 
DO UPDATE SET data = EXCLUDED.data, status = EXCLUDED.status;
"
```
