# Workspace Context & Conversation Isolation Rule

## Purpose
Ensure that all conversations, historical context, search queries, and memory retrievals in this repository are strictly scoped to the `HR-Payroll-Management-System` workspace.

## Guidelines
1. **Workspace Boundary Enforcement**:
   - Only consider code, conversations, artifacts, and instructions relevant to the `HR-Payroll-Management-System` codebase (`d:\GIT-HUB\HR-Payroll-Management-System`).
   - Disregard any extraneous conversation summaries, history, or transcripts from other workspaces (such as Arduino, RVM, SplitEasy, or other unrelated projects).

2. **Session & History Scoping**:
   - When asked about previous work, recent changes, or project history, inspect the local git log, repository documentation, and conversations specific to `HR-Payroll-Management-System`.
   - Never import dependencies, configurations, or context from unrelated projects into this codebase.
